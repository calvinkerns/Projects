    How to play
    
    
  
    

  
    The game
    
  
      
    
    • The board is 21×21. Every tile belongs to you, your opponent, or nobody, and holds some mass. Walls block movement.
      • 
    
    • Each tick your bot returns up to  orders. An order pushes half the mass on one of your tiles (or all of it) into a neighbouring tile.
      • 
    
    • Every order costs 1 energy. You gain  per tick and can bank up to , so you can save up for a big coordinated strike or spend as you go.
      • 
    
    • Combat is subtraction. Opposing masses arriving on the same tile cancel out, and you only capture a tile by bringing strictly more mass than is on it.
      • 
    
    • Your core and the wells you own gain 1 mass every tick. Other tiles gain 1 every  ticks. Neutral wells start with  mass.
      • 
    
    • Capture the enemy core to win. If nobody does, the most tiles after  ticks wins. You can only see tiles next to tiles you own.
      • 
  
    

  
    Your bot
    
  
    Define function bot(state) and return an array of orders. You can also define function init(state), which runs once before the first tick. Top-level variables keep their values for the whole match.
    
  
    function bot(state) {
  // Push half of my core's mass east, every tick.
  const myCore = state.cores[0];
  return [{ from: myCore, dir: 1 }];
}
    

  
    Orders
    
  
    { from, dir, all }: from is a tile index (y * 21 + x), dir is 0 north, 1 east, 2 south or 3 west, and all: true sends everything instead of half. Invalid orders are skipped and cost nothing.
    

  
    The state object
    
  
    
    
    
      
    tickCurrent tick, starting at 0
    
      
    meYour player number, 0 or 1
    
      
    energyYour current energy
    
      
    maxOrders, maxTicks, rulesGame constants
    
      
    W, HBoard width and height (21)
    
      
    terrainInt8Array: 0 plain, 1 wall, 2 well, 3 core
    
      
    ownerInt8Array: -2 fog, -1 neutral, 0 or 1
    
      
    massInt32Array: -1 under fog
    
      
    visibleUint8Array: 1 where you can see
    
      
    cores[yourCore, enemyCore] as tile indices
    
      
    wellsTile indices of every well
    
      
    tileCount[yours, theirs]: always visible
    
      
    myMassYour total mass
    
    
    
  
    

  
    Limits and sandbox
    
  
      
    
    • Each tick must finish within  ms (init:  ms) or your bot forfeits.
      • 
    
    • If bot() throws, you do nothing that tick and the error shows in the console.
      • 
    
    • Bots run in a Web Worker with no network access. Math.random is seeded, so every match replays exactly, and console.log prints to the console panel.
